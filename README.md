## Install notes (Windows)

1. Close DOOM: The Dark Ages before the first run of a new trainer build.
2. Unpack or run only what MoggyDay gave you for `doom-dark-ages-trainer`.
3. Start the trainer, then start DOOM: The Dark Ages (or the order printed on the live page if it differs).
4. Enable one or two toggles, not the whole +22 list at once.
5. Make a spare save. God mode and resource edits are hard to undo if you overwrite the only slot.

Antivirus sometimes flags trainers. That is normal for this file class. Download again from the same URL if the hash on the site changes.

## If something does not work

- The game patched and the v2.1.0 heading is older than the DOOM: The Dark Ages build you launched — wait for MoggyDay to bump the page.
- You used a bookmark that is not `/f/doom-dark-ages-trainer` — switch to the URLs in the table above.
- Only the DLL or only the EXE was copied from a friend — get the pair from the site.
- Overlay or other injectors are running — turn them off and retry.
